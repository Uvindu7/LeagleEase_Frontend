Project Overview

The LegalEase frontend is developed using React and JavaScript, with Tailwind CSS for styling and React Router for navigation. It provides a user friendly and responsive interface that allows clients to register and log in, browse lawyer profiles, view lawyer availability, book consultation appointments, and make online payments through Stripe. The frontend also includes interfaces for managing appointments and lawyer availability, as well as an OTP-based password recovery process. It communicates with the backend through API requests to retrieve and submit data, providing users with a smooth and interactive experience

Features : 

User registration and login
Browse lawyers and view lawyer profiles
Book appointments with lawyers
Manage lawyer availability and appointments
Online payments using Stripe
Password reset with OTP verification

Technologies Used : 

React
JavaScript
HTML5
Tailwind CSS
React Router
Stripe integration
